# Asset credits — «Мозаика миров» / «Mosaic of Worlds»

All 16 in-game paintings are derivative works made from photographs hosted on
[Wikimedia Commons](https://commons.wikimedia.org/). Every source file was
downloaded once at build time; nothing is loaded from a CDN at runtime.

Processing applied to every source: EXIF rotation, a square crop, resizing to
1600×1600 (full) and 600×600 (thumbnail), a light colour grade and vignette.
Several fantasy worlds also received bespoke compositing (nebula/starfield,
cloud sea, fireflies, duotone). The resulting files live in
`public/images/full/` and `public/images/thumbs/`.

> attribution only. CC0 / public-domain sources have no attribution

The supplied MP3 files were transcoded to AAC-LC, 128 kbps, 44.1 kHz for the
build (`public/music/*.m4a`). The source files stay in `music/`.

Licensing responsibility for the supplied recordings remains with the project
owner. Keep this credit block with the game, and verify the final clearance
before publishing.

Music is played through the Web Audio API from a hidden media element, so the
game never shows native audio controls. The playlist lives in
`src/core/audio.ts`.

## Sound effects

Sound effects are generated at runtime with the Web Audio API (oscillators,
filtered noise and envelopes). No third-party SFX files are used.
